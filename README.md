# GREEN-API Chat

React chat for text messages via GREEN-API (WhatsApp).

```bash
npm install
npm run dev
```

Open http://localhost:3000. Authorize a WhatsApp instance in GREEN-API, then enter its API URL, `idInstance` and `apiTokenInstance`. Enable incoming notifications and leave `webhookUrl` empty for HTTP API (the app offers a setup button). Use a phone number with country code.
